# homebrew-tap

Homebrew tap for [Noctra](https://github.com/onelastcommit/noctra), the autonomous Linear→PR agent.

```bash
brew install onelastcommit/tap/noctra
```

Already tapped `ahmadAlMezaal/tap`? It keeps working because GitHub redirects the old name, or re-tap with `brew untap ahmadAlMezaal/tap && brew tap onelastcommit/tap`.
